## 当前核心数字（1000 场景，801 训练 / 199 测试）

点级（micro-F1）：基线 tau=2.0mm 0.482（tau 扫描）/ RF 0.911 / GBM 0.902。
分类别 RF F1：掉漆 lee 0.765，裂纹 crack 0.874，凹坑 dent 0.876，变形 deform 0.965。

场景级（测试集）：
- 基线：面积 MAE 0.18–0.34 m²，体积 MAE 1123–1600 cm³，定位误差 0.16–0.88 m（掉漆/凹坑仅 29–34% 在 0.5 m 以内），健康叶片误报 0.40 m² / 1704 cm³
- RF：面积 MAE 0.020–0.058 m²，体积 MAE 56–236 cm³，定位误差 0.009–0.077 m（95–100% 在 0.5 m 以内），健康误报 0.004 m² / 14 cm³

## 特征消融（120 场景，特征子集逐步叠加，RF）

A 原始偏差 [dev_mm, abs] 0.417（比传统基线 0.482 还差！）
B +局部统计 0.666；C +一致性 0.666；D +位置 (x, z) 0.868；
E +法向 0.891；F 完整 12 维 0.889。

解读：增益不来自原始偏差幅值，而来自上下文信息——局部统计 + 位置感知
消除了 LE/TE 伪影带；法向带来最后一步小幅提升；12 维没有过拟合。

## 传感器鲁棒性（200 场景；RF 仅在标称传感器参数下训练；
tau/thr 在标称训练集上调好；同一组损伤在 8 种扫描条件下重新扫描）

| 条件     | 基线   | RF    |
|----------|--------|-------|
| 标称     | 0.468 | 0.889 |
| 噪声 0.5 | 0.468 | 0.802 |
| 噪声 1.0 | 0.458 | 0.301 |
| 缺失 0.3 | 0.467 | 0.882 |
| 缺失 0.5 | 0.455 | 0.869 |
| 角度 1.0°| 0.422 | 0.697 |
| 角度 2.0°| 0.365 | 0.407 |
| 平移 15mm| 0.452 | 0.879 |

解读：RF 对中等扫描退化稳健（点缺失、平移、轻度噪声/角度），但超出训练时
的传感器分布会明显退化（噪声 1.0 → 0.301，角度 2.0° → 0.407，均低于传统
基线）。基线"看起来不随条件变化"只是因为它的全局 2 mm 阈值本来就粗粒度
过度检测（它的 F1 从来没有是对的）。
论文的诚实结论：上下文感知检测用 OOD 传感器敏感性换来了巨大的名义增益；
修复方案 = 训练时做传感器噪声增广（后续工作 / 可选实验）。

## 剩余具体任务（建议顺序）

1. GPU 机器：`pip install torch`，然后逐个骨干
   `python deep/run_pointnet.py --num 1000 --backbone <b>`，
   以及预训练 + 微调组合（`--init-from`）。把 micro-F1 和场景级指标与
   RF 一行对比（深度模型比手工特征强多少？强多少才算值得？）。
2. 可选：RF 传感器噪声增广训练（标称 + 噪声/角度混合训练集），
   恢复 OOD 鲁棒性；扩展 `run_robustness.py`。
3. 真实数据验证：获取或整理 30–50 个真实扫描场景；至少用冻结的
   传统 + RF 管线直接跑（真实数据上零训练）。
4. 多种子：RF + 一个深度骨干用种子 1/2/3 重跑；报告均值±标准差。
5. 可选：I1 弱配准双编码骨干（扫描 + 名义几何的交叉注意力）、
   异常检测基线（PatchCore 类）、2D-YOLO 跨视角对照实验（论证 3D 模态的必要性）。
